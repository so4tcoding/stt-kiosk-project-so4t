🎙️ 고객 대화형 반중력 키오스크 (Touchless AI Kiosk)
100% 음성으로만 동작하는 시니어(초고령층) 및 베리어프리 맞춤형 AI 키오스크 프로젝트입니다.
마이크 권한 및 아두이노 시리얼 통신을 위해 반드시 로컬 웹 서버 환경에서 실행해야 합니다.

⚙️ 1. 사전 준비 (Prerequisites)
이 프로젝트는 파이썬(Python)의 기본 내장 서버 모듈을 사용하여 실행됩니다.

Python 설치: 컴퓨터에 파이썬이 설치되어 있어야 합니다. (cmd 또는 파워셸에서 python --version을 입력해 확인 가능)

운영체제: Windows 10/11 권장 (PowerShell 사용)

🚀 2. 1초 만에 실행하는 방법 (Windows)
귀찮은 터미널 명령어 입력 없이, 준비된 스크립트 파일 하나로 서버 구동과 브라우저 실행을 동시에 처리할 수 있습니다.

프로젝트 폴더(kiosk_project)를 열어 빈 공간에 Shift + 마우스 우클릭을 하고 [여기에 PowerShell 창 열기] 또는 [터미널에서 열기]를 클릭합니다.

터미널 창이 뜨면 아래 명령어를 복사하여 붙여넣고 엔터를 누릅니다. (로컬 서버 세팅 스크립트를 생성하는 과정입니다. 최초 1회만 하시면 됩니다.)

PowerShell
@"
Write-Host "키오스크 로컬 서버 세팅 중..." -ForegroundColor Cyan
Start-Job {
    Start-Sleep -Seconds 2
    Start-Process "http://localhost:8000/kiosk_stable_current.html"
} | Out-Null
python -m http.server 8000
"@ | Out-File -FilePath ".\start_kiosk.ps1" -Encoding utf8
이제 실행 스크립트가 만들어졌습니다. 터미널에 아래 명령어를 입력하여 키오스크를 실행합니다.

PowerShell
.\start_kiosk.ps1
2초 뒤 자동으로 웹 브라우저가 열리며 키오스크 화면(http://localhost:8000/...)이 나타납니다!

종료할 때: 터미널 창을 클릭하고 Ctrl + C를 누르면 서버가 안전하게 종료됩니다.

🚨 3. 에러가 발생하나요? (Troubleshooting)
만약 .\start_kiosk.ps1 실행 시 빨간색 에러 글씨(보안 오류, PSSecurityException 등)가 뜬다면, 윈도우 스크립트 실행 권한이 막혀있기 때문입니다.

이 경우 터미널에 아래 명령어를 한 번만 입력하여 권한을 허용해 주세요.

PowerShell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
명령어 입력 후 Y를 누르고, 다시 .\start_kiosk.ps1 을 실행하시면 정상 작동합니다.

💻 4. 코드 수정 및 개발 가이드
이 프로젝트의 메인 파일은 kiosk_stable_current.html 입니다. 코드를 수정하고 결과를 확인하는 방법은 다음과 같습니다.

[기본 방식]

에디터(VS Code, 메모장 등)로 kiosk_stable_current.html 파일을 엽니다.

코드를 수정하고 저장(Ctrl + S)합니다.

파워셸 스크립트로 열어둔 브라우저 화면으로 돌아가 F5 (새로고침)를 누르면 변경 사항이 즉시 적용됩니다.

[VS Code 사용자 꿀팁 (Live Server)]

VS Code 확장 프로그램에서 Live Server를 설치합니다.

kiosk_stable_current.html 파일을 띄워두고, VS Code 우측 하단의 [Go Live] 버튼을 클릭합니다.

앞으로는 파워셸을 켤 필요 없이, 코드를 저장(Ctrl + S)할 때마다 브라우저가 자동으로 새로고침 됩니다.

이대로 깃허브에 올리시면 다른 개발자나 평가자분들이 보더라도 "문서화가 엄청 깔끔하게 잘 되어 있다"고 느끼실 겁니다! 더 추가하고 싶은 설명이나 궁금한 점이 있으신가요?
